Ringkasan Semua Pelajar

Cetakan LAM-PT-04-01

Isi butiran kursus dalam Tetapan sebelum cetak. Nama Ketua Pemeriksa & Ketua Jabatan diambil dari helaian Konfigurasi.

Rekod Prestasi

Klik tajuk lajur untuk susun ikut kelas, nama, jumlah atau gred.

Analisis Gred

Dikira di backend: action=analisisGred

Tekan “Muat semula” untuk mengira analisis.

Simulasi & Sisihan Piawai

Dijana di backend: action=simulasiSisihanPiawai — bukan pengiraan dalam pelayar.

Bilangan pelajar / min / maks / taburan hanya digunakan untuk mod “Jana markah rawak”. Seed sama = keputusan sama.

Belum ada simulasi dijalankan.

Moderasi — LAM-PT-02

Sampel markah rendah / sederhana / tinggi. Dijana oleh action=moderasiPT02.

Tekan “Jana sampel” untuk memilih 3 rendah / 3 sederhana / 3 tinggi.
